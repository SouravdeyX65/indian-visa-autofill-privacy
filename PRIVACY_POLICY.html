Privacy Policy - Indian Visa Autofill (UNOFFICIAL)

Extension Version: 1.0.3  |  Last updated: 25 November 2026

Indian Visa Autofill (UNOFFICIAL) is an independent browser extension. It is not affiliated with, authorised by, or endorsed by the Government of India, the Government of Bangladesh, or any visa, immigration, aviation, or port authority.

Information the extension handles

The extension only handles information that users actively choose to enter, import, scan, or capture for form preparation, which may include:

  • Applicant identity, family, address, travel, and passport details.
  • Saved profiles, hotel selections, and extension settings/preferences.
  • Imported documents, images, signatures, PDF content, and user-initiated page screenshots.

This information constitutes sensitive personal information and is processed solely to assist the user in filling forms and preparing required documents.

Supported websites and form interaction

When active on supported portals, the extension reads visible form fields and populates values selected by the user:

  • Indian Visa Online (Bangladesh) (indianvisa-bangladesh.nic.in)
  • Indian e-Arrival Portal (indianvisaonline.gov.in)
  • Air Suvidha (airsuvidha.civilaviation.gov.in)
  • A-Challan Travel Tax Portal (achallan.gov.bd / www.achallan.gov.bd)
  • BLPA Land Port Passenger Tax Portal (passenger.blpa.gov.bd)

Multi-step form session values (such as Air Suvidha step data) may be temporarily retained in local extension storage (for up to 6 hours) so details carry over between steps, and are cleared when a new profile is loaded.

Local storage and on-device processing

All profiles, preferences, and temporary form states are stored locally on the user's device using Chrome extension storage (chrome.storage.local). When enabled by the user, saved PDFs, processed photos/signatures, and screenshots are stored in the extension's local browser database (IndexedDB). PDF parsing, background removal/photo formatting, and bundled Tesseract OCR run locally in the user's browser. The extension does not operate any developer-owned backend server or user account system.

CAPTCHA recognition and third-party services

By default the optional CAPTCHA helper recognises text locally on the user's device using OCR components bundled with the extension. If the local result is not sufficiently confident or the user invokes fallback recognition, only the cropped CAPTCHA image is transmitted over HTTPS to OCR.space (api.ocr.space) for text extraction. OCR.space is an independent third party governed by its own privacy policy.

Optional Google Gemini (off by default). A user may choose to enter their own Google Gemini API key in the extension. Only after the user enters a key, the extension sends the cropped CAPTCHA image (and the user's own API key, as required by Google's API) over HTTPS to Google's Gemini API to read the text, and this is tried before the local and OCR.space methods. Without a key, nothing is ever sent to Google. The key is stored only in local extension storage on the device, is not included in exported backups, and is removed when the user clears it or uses the delete-all option. Google processes the request under its own terms and privacy policy, and the user's own Gemini account or quota applies.

In every case, applicant profiles, passport details, and other form fields are never included in these requests. Users who disable or do not use the CAPTCHA helper never trigger any of these external requests.

Data sharing, sale, and tracking

The developer does not collect, receive, sell, rent, or trade any user data. Aside from the optional CAPTCHA-image requests to api.ocr.space and, only if the user adds their own key, Google Gemini (both described above), user data is never transmitted to external servers. The extension contains no advertisements, telemetry, or third-party analytics trackers, and requires no account.

Backups, PDFs, and screenshots

Users may export their profiles as a JSON backup file. Exported JSON backups are unencrypted and may contain sensitive personal details; users are responsible for keeping backup files secure. If the user enables saving PDFs or captures a full-page screenshot (via the extension controls or Alt+Shift+S), those files remain in local storage until deleted. Users can view, download, or delete saved items anytime in the extension's Files section.

User controls and data deletion

Users have full control over their local data and can edit or delete individual profiles and saved files at any time. Using the extension's delete-all option permanently removes all locally stored extension data. Uninstalling the extension or clearing Chrome extension storage also removes local data. Any exported backup files saved to disk must be deleted manually by the user.

Accuracy and application submission

This extension is strictly a client-side form-filling and document preparation helper. It never submits visa or tax applications automatically, never processes payments, and does not guarantee visa eligibility or extraction accuracy. Users must carefully review all populated fields and complete submissions themselves.
